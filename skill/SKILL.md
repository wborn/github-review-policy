# GitHub Review Policy

Use this skill when reviewing or re-reviewing GitHub pull requests, preparing review comments, resolving addressed review threads, classifying findings as blocking or non-blocking, or submitting/verifying GitHub reviews.

## Required references

Always read:

- `references/generic.md`

Then read the matching project-specific reference when applicable:

- openHAB: `references/openhab.md`
- OpenRemote: `references/openremote.md`
- jUPnP: `references/jupnp.md`

## Application

- Apply the generic policy to every repository.
- Project-specific policy adds to or overrides generic policy only where explicitly stated.
- Do not import one project's conventions into another project.
- Follow repository-local `AGENTS.md`, `CONTRIBUTING.md`, relevant `README.md`, and other repository guidance as required by the generic policy.
- Use the full review workflow, including pre-submission presentation, review-thread handling, and post-submission verification.
